EMOJI REFERENCE FOR PYTHON + VS CODE
====================================

HOW TO USE
----------
1. Open this file in VS Code.
2. Select an emoji.
3. Right-click -> Copy.
4. Open your Python file and paste it inside a string.
5. Run the program to verify the emoji displays correctly.

Example:
message = "Email sent successfully! 📧 ✅"
print(message)

14. UTF-8 AND UBUNTU INSTRUCTIONS
---------------------------------

Python 3 supports Unicode strings by default. You normally do
NOT need to change your Python installation to use emojis.

A. Check the Python version:

    python3 --version

B. Check the terminal locale:

    locale

Look for UTF-8 in values such as LANG or LC_CTYPE.

C. If the Ubuntu terminal does not display emojis correctly:

    sudo apt update
    sudo apt install locales
    sudo locale-gen en_US.UTF-8

Then add the following to ~/.bashrc if necessary:

    export LANG=en_US.UTF-8
    export LC_ALL=en_US.UTF-8

Reload your shell:

    source ~/.bashrc

If the locale is not installed or configured correctly, consult
your Ubuntu distribution's locale configuration before setting
LC_ALL globally.

D. Check VS Code file encoding:

    1. Open the Python file.
    2. Click the encoding indicator in the bottom status bar.
    3. Select "Save with Encoding".
    4. Choose "UTF-8".

E. Test emoji output:

    python3 -c 'print("Hello 😀 🚀 ✅ 📧")'

If the emojis display correctly, your Python and terminal setup
can handle those characters.


15. IMPORTANT NOTES
--------------------
- Save Python source files as UTF-8.
- Python 3 strings can contain emojis directly.
- Your terminal font must support emoji glyphs.
- Some emojis may appear differently across operating systems.
- If an emoji appears as a square, the issue may be the terminal
  font rather than Python's encoding.
- GIFs are animated image files, not individual text characters.
  You cannot paste an animated GIF directly inside a Python
  string as an emoji. Use a GIF file path or URL if your program
  needs to display an animation.
